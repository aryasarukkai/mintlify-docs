To ask our team to change titles, credits or artwork on a release that's already been delivered, use the **Request an edit** card on the release's **Delivery** tab. You tell us what should change, our team reviews the request, makes the change and sends the update to the stores. The release stays in stores while we do this.

<Info>
Some releases have a **Request changes** button at the top of the release page instead, which lets you make the edit yourself. See [Change a release that's already live](/after-release/change-a-release-thats-already-live). If that button says "Changes to this release have to be made by our team", use the **Request an edit** card described here.
</Info>

## Who can request an edit

You need the **Admin** role on the account that owns the release. Members and collaborators can see the card but can't send a request. They see "Only an account admin can request an edit".

## Send a request

1. Open **Releases** and click the release.
2. Open the **Delivery** tab.
3. On the **Request an edit** card, click **Request an edit**.
4. Say exactly what should change, for example the corrected title or the credit to add. You can write up to 2,000 characters.
5. Click **Send request**.

The card now shows "Requested" with how long ago, and "waiting for review". If you change your mind before we review it, click **Withdraw request**.

## What happens next

We send you a notification when we've reviewed the request:

* **Approved**: we make the change and send it to the stores. Stores usually show the update within a few days. The card then says "Your last edit was approved".
* **Declined**: the card says "Your last request was declined", with a note from our team if there is one.

You can have one edit request waiting at a time. Once it's been reviewed, you can send another.

## When you can't request an edit yet

The card tells you why if a request can't be sent right now:

| Message | What it means |
|---|---|
| "Still being delivered to …" | The release is still going out to some stores. You can request an edit once delivery has finished. |
| "The stores are still taking the latest delivery. Edits open 30 minutes after delivery." | Wait for the time shown on the card, then try again. |
| "This release is locked while it is being processed or reviewed for delivery." | Try again once delivery has finished. |
| "Only a delivered or live release can be edited this way." | The release hasn't been delivered yet. If it's a draft or has revisions requested, edit it in the release builder. |

If the card says "Titles, artwork and credits can be changed. The tracklist, UPC and release date cannot.", you can send a request. Only those details can change on this release.

## Common questions

### Will my release come down while you make the change?
No. The release stays in stores while we make the change.

### Can I change the audio or add a track?
Not with an edit request. Contact us and we'll tell you the options for that release.

### I don't see the Request an edit card.
The card only appears on releases that have been delivered, and not on releases that are being taken down or have been taken down. If your release is delivered and you still don't see it, send us a message from the chat on this page, or email team@ammdistro.com.
