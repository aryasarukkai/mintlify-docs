To fix titles, artists, genre, the label line, explicit ratings, lyrics or credits on a release that's already in stores, click **Request changes** on the release. Once we approve the request, you edit the release, we review your changes, and we send them to the stores. The release stays in stores the whole time.

## What you can and can't change

| You can change | You can't change |
|---|---|
| Release and track titles | Audio |
| Artists | Artwork |
| Genre | Tracklist (adding, removing or reordering tracks) |
| The label line | ISRCs |
| Explicit ratings | Release date |
| Lyrics and credits | |

For anything in the right-hand column, contact us.

<Info>
Request changes is on the web dashboard only. It isn't in the mobile app.
</Info>

## 1. Send a request

1. Open **Releases** and click the release. It must be **Delivered** or **Live**.
2. Click **Request changes** at the top right.
3. Describe what you want to change. Be specific, for example which track and what the new title should be. You can write up to 2,000 characters.
4. Click **Send request**.

<img src="https://ammdistro.com/helpdesk/distro-request-changes-dialog.webp" alt="The Request changes dialog with a description of the change typed in and the Send request button" style={{ maxWidth: "600px" }} />

A banner at the top of the release now says **Change request sent**, with what you asked for. If you change your mind, click **Withdraw request**.

## 2. Make your changes

When we approve the request, the banner changes to **You can edit this release** and an **Edit release** button appears in the banner (and **Edit Release** at the top of the page). We may add a note from our team.

1. Click **Edit release**. The builder opens with the banner **Editing a release that is already in stores**.
2. Make your changes. Fields you can't change are locked.
3. Scroll to **Your changes** at the bottom. It lists every change next to the old value.
4. Click **Submit changes for review**.

![The banner shown in the builder while you edit a release that is already in stores](https://ammdistro.com/helpdesk/distro-editing-live-release-banner.webp)

To start again, click **Discard changes**. This puts the release back to how it was delivered.

## 3. We review and send the update

* **Your changes are being reviewed**: we check the changes before they go to stores. If something needs fixing, we send the release back to you with a note.
* **Your changes are being sent to stores**: stores usually show updated details within a few days.

Your release keeps its UPC and ISRCs, so streams, playlists and links aren't affected.

## If you see "Changes to this release have to be made by our team"

Not every release can be changed this way. If the dialog says **"Changes to this release have to be made by our team. Contact support."**, send us a message from the chat on this page, or email team@ammdistro.com. Tell us the release name and exactly what should change, and we'll make the change for you.

## Other messages you might see

* **"Only a release that is out in stores can be changed this way."** The release isn't **Delivered** or **Live** yet. If it's still a draft or has revisions requested, edit it in the builder as usual.
* **"A change request is already in progress for this release."** Finish or withdraw the current request first.
* **"Nothing has changed yet."** You clicked **Submit changes for review** without changing anything.

## Common questions

### Will my release come down while I edit?
No. The release stays in stores while you edit and while we review.

### I uploaded the wrong audio or artwork.
Audio and artwork can't be changed with a request. Contact us and we'll tell you the options for that release.

### Can I add a track to a live album?
Not with a request, because the tracklist can't change. Contact us to talk through the options.
