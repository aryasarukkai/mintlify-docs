title: "Take a release down"
description: "Account admins can request a takedown from the release's Delivery tab, or for several releases at once from the Releases page."
---

If you're an admin on the account, you can ask for a release to be taken down from the dashboard. Our team reviews each request before anything changes. If it's approved, the release is removed from every store.

## Request a takedown for one release

1. Open the release and go to the **Delivery** tab.
2. In the **Takedown** card, click **Request takedown**.
3. Say why the release should come down, then click **Send request**.

The card then shows when you made the request and that it's waiting for review. Until we review it, you can click **Withdraw request** to cancel it.

## Request takedowns for several releases

1. On the **Releases** page, tick the releases you want to remove.
2. Click **Request takedown** in the bar at the bottom of the page.
3. The dialog lists which releases can be requested and, for any that can't, the reason. Say why they should come down, then click **Request takedown** (or **Request 3 takedowns**, for example).

You can withdraw any of these requests from the release's page until we review it.

## Who can request a takedown

* Only account admins. Members and collaborators can see the **Takedown** card but can't send a request.
* Only for a release that is **Delivering**, **Delivered** or **Live**.
* The **Takedown** card isn't shown for every release. If you don't see it, or it says requests aren't available for the release, send us a message from the chat on this page, or email team@ammdistro.com, and we'll handle it.

If the reason is a mistake that an edit could fix, such as a typo in a title or a missing credit, you may not need a takedown. See [Change a release that's already live](/after-release/change-a-release-thats-already-live).

## What you'll see on the release

| Status | What it means |
|---|---|
| **Takedown requested** | We've asked the stores to remove this release. This usually takes a few days. |
| **Taken down** | Removed from stores. |

If we decline a request, the **Takedown** card says so, with our note, and you can send a new request.

Each store removes the release on its own schedule, so it can stay visible in some stores for a few days after the takedown.

## Deleting vs taking down

You can only **delete** a release yourself while it's a **Draft** or after it's been **Rejected**. Once a release is in stores, it has to be taken down instead.

## Common questions

### Will I still get paid for streams from before the takedown?
Stores report earnings a month or two after the streams happen, so earnings from before the takedown can still appear on later statements.

### Can I put the release back up later?
Bringing a release back after a takedown means submitting it again. Contact us and tell us which release it was.

### Can I take a release down from just one store?
The dashboard request removes the release from every store. To remove it from only some stores, send us a message from the chat on this page, or email team@ammdistro.com, and say which stores.

### Someone else uploaded my music, or my release was removed because of a copyright claim.
Contact us with links. See [Copyright claims and counter-notices](/rights-and-policies/copyright-claims-and-counter-notices).
