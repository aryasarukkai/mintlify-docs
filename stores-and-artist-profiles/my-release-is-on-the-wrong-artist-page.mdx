If your release shows up on another artist's page, or someone else's release shows up on yours, contact us with the details and we'll get it moved. The fix has to go through the store, so changing the link in your account won't move a release that's already out.

## What to send us

Send us a message from the chat on this page, or email team@ammdistro.com, with:

* The release name, and the store where it's on the wrong page (for example Spotify or Apple Music).
* A link to the page it's on now.
* A link to the artist page it should be on. If the artist has no page on that store yet, say so; the store can create a new one.

<Tip>
Include every store where you see the problem. Each store fixes its own artist pages.
</Tip>

## Why this happens

Stores decide which artist page a release belongs on from the artist profile we deliver with it. Most mix-ups come from one of these:

* **No profile was linked.** Without a Spotify link, the stores guess which artist page the release belongs to. If another artist has the same name, the release can land on their page. The release check warns about this before you submit.
* **The wrong profile was linked.** For example, a profile with a similar name was picked in the search.

## Why you can't fix it from your account

Once a release with an artist has been delivered, that artist's filled-in profile links are locked. Changing our link wouldn't move the release in the store; it would only make our records disagree with the store. If you try, you'll see: "This artist has been delivered to the stores with these profile links, so they are locked. Contact support if a link is wrong."

## Prevent it on your next release

1. Before you submit, link the right **Spotify profile** (and **Apple Music**, if the artist has one) for every artist on the release. See *Link your Spotify and Apple Music artist profiles*.
2. If you see *That Spotify profile is called "X", not "Y"*, stop and check you picked the right artist before confirming.
3. For a brand-new artist with no profile yet, leave the links empty so the stores create a new page.
4. Answer the **Spotify profile protection** question correctly for each artist. See *Spotify Artist Profile Protection*.

## Common questions

### Someone else's release is on my artist page.
Contact us with a link to your artist page and the release that isn't yours.

### My release is missing from my artist page, but I can find it by searching.
That usually means it's on a different artist page. Search for the release, open the artist name on it, and send us that link along with the correct one.

### How long does a fix take?
It depends on the store, since each store makes the change itself. If you haven't heard from us, reply in the same conversation.
