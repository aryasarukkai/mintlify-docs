Linking an artist's Spotify and Apple Music profiles tells the stores which artist page your release belongs on. Do it before you submit. If an artist has no profile yet, leave the links empty and the stores will create one when the first release is delivered.

## Why it matters

Stores match a release to an artist page using the profile you link. With no Spotify profile linked, the stores have to guess which artist page the release belongs to, and it can end up on another artist's page with the same name. The release check before submitting warns you when an artist has no Spotify profile linked: if they already have one, link it so the release goes on the right artist page; if they're new, a page is created when the release goes live.

## Link profiles when you add an artist in the builder

1. In the release builder, find **Artists** and type the artist's name in **Search or add an artist…**.
2. If they're not on your account yet, click **Create "Name"**.
3. Under **Spotify profile**, search for the artist and pick the right profile, or paste the profile link. If they don't have a Spotify page yet, click **Not on Spotify yet? Create without a profile**. Their Spotify page is created when their first release goes live.
4. Under **Apple Music**, search or paste the profile link. This one is optional.
5. Under **Legal name**, enter the artist's real **First name** and **Last name**. You can add it later, but it's needed before you submit.
6. Click **Create artist**.

The artist chip on your release shows small Spotify and Apple Music marks when the links are set. If something is missing, the chip turns amber; hover over it to see what it still needs, for example "Still needs: Spotify profile".

You can also manage artists in **Settings → Artists**. See *Manage your artist profiles*.

## The profile name must match

When you add a link, we check it with the store:

* If the link doesn't lead to an artist profile, you'll see "No Spotify artist found at that link".
* If the profile has a different name from your artist, you'll see a message like *That Spotify profile is called "X", not "Y". Confirm it's the right artist to save it.* Only confirm if you're sure it's the same artist, for example the same name written slightly differently.
* If the store can't be reached, you'll see "Could not reach the store to check that link. Try again."

When a Spotify profile spells the name differently only in capital letters, spacing or punctuation, we use Spotify's spelling for the artist.

## Why we need a legal name

Every artist needs a legal first and last name before a release can be submitted. The chip shows **Legal name on file** or **No legal name yet — needed before submitting**. The legal name is used for songwriting credits, because stores reject single names there. Fans don't see it; your artist name stays as it is.

## New artists with no profile yet

Leave the Spotify and Apple Music links empty. When the first release is delivered, the stores create new artist profiles. In most cases we then fill in the empty links on your account automatically. If a link is still empty a few days after the release is live, find the new profile in the store and add the link yourself. Empty links can always be filled in.

## Links lock after delivery

Once a release with this artist has been delivered to the stores, the links that are filled in are locked so our records keep matching the stores. Empty links can still be filled in.

If you try to change a locked link, you'll see: "This artist has been delivered to the stores with these profile links, so they are locked. Contact support if a link is wrong."

<Info>
Changing a link on our side doesn't move a release that's already in stores. If a release went to the wrong page, contact us so we can fix it with the store.
</Info>

## Common questions

### I have a profile on Spotify but not on Apple Music. What do I do?
Link Spotify and leave Apple Music empty. After the release is delivered, Apple Music matches it to a profile or creates one. You can add the Apple Music link to the artist at any time, since empty links can always be filled in.

### My artist has the same name as another artist.
Link the right Spotify profile before you submit. That is what keeps your release off the other artist's page.

### A link is locked and it's wrong.
Send us a message from the chat on this page, or email team@ammdistro.com, with the artist name and the correct profile link.
